# Information Security Policy (ISO/IEC 27001:2022)

This document outlines the security policies, cryptographic standards, and vulnerability disclosure process for the profile repository of **Daffa Jaya Perkasa**.

---

## 1. Cryptographic Baseline
- **Identity Verification**: All commits across all public and private repositories are signed using an **Ed25519 GPG key** (`7573912AF4141E99`).
- **Secret Hygiene**: Zero hardcoded credentials, access tokens, or private keys are permitted.

---

## 2. Vulnerability Reporting
To report security concerns or vulnerabilities across any software projects:
- **Email**: [dafayape@gmail.com](mailto:dafayape@gmail.com)
- **Response SLA**: Initial triage within 24 hours.
